# SAMTRADE

יומן מסחר מודולרי עם Firebase, נתוני שוק, תיעוד יומי וניתוח ביצועים.

## הרצה מקומית

הפרויקט משתמש ב-ES modules וב-Service Worker, ולכן יש להריץ אותו דרך שרת מקומי ולא לפתוח את `index.html` ישירות.

```bash
python3 -m http.server 5500
```

לאחר מכן יש לפתוח בדפדפן:

```text
http://localhost:5500
```

## מבנה נתוני היומן

העסקאות והטרנזקציות הקיימות אינן משתנות. השאלון היומי נשמר באוסף נוסף ונפרד:

```text
users/{uid}/dailyJournal/{YYYY-MM-DD}
```

כל מסמך כולל את התאריך, דירוג מצב הרוח, דירוג העייפות, דירוג איכות היום והערה אופציונלית. מסך הסטטיסטיקות משייך את הרשומה לעסקאות ש-`OPEN_DATE` שלהן זהה לתאריך הרשומה.

אם כללי Firestore הקיימים מאפשרים למשתמש לקרוא ולכתוב לכל תתי-האוספים תחת `users/{uid}`, אין צורך בשינוי נוסף. אם הכללים מוגבלים רק ל-`positions` ול-`transactions`, יש להוסיף הרשאה גם ל-`dailyJournal`.

Firebase project identifiers, מבנה העסקאות הקיים, Authentication, כתובת ה-GitHub Pages וה-PWA נשארו ללא שינוי.
## מסך נתוני מניות

הפרויקט כולל מסך שוק נפרד עם חיפוש טיקר, רשימת מעקב מקומית, גישה מהירה לפוזיציות פתוחות וגרף TradingView מתקדם. הגרף כולל מעבר בין נרות וקו, טווחי זמן, כלי ציור כגון קו מגמה, אינדיקטורים וממוצע נע. נתוני המחיר המסכמים ממשיכים להשתמש במפתח Finnhub שכבר מוגדר במערכת.

רשימת המעקב והטיקר האחרון נשמרים בדפדפן בלבד ואינם משנים את מבנה Firestore.


## תמונת מצב נרחבת

נוסף מסך `תמונת מצב` נפרד מהמסך הראשי. במסך ניתן לעבור בין:

- פוזיציות סגורות בלבד
- פוזיציות סגורות ופתוחות יחד
- פוזיציות פתוחות בלבד

המדדים כוללים רווח ממומש, רווח לא ממומש, רווח כולל משוער, שווי פוזיציות פתוחות, חשיפה, מספר פוזיציות ו-Win Rate. מדדי איכות כגון Win Rate ממשיכים להיות מחושבים מפוזיציות סגורות בלבד.

כדי לבנות מגמה היסטורית אמיתית גם עבור פוזיציות שעדיין פתוחות, המערכת שומרת צילום יומי באוסף נוסף:

```text
users/{uid}/portfolioSnapshots/{YYYY-MM-DD}
```

הצילום נשמר לאחר שמחירי כל הפוזיציות הפתוחות נטענו בהצלחה, וכולל רווח ממומש, רווח לא ממומש, רווח כולל משוער ושווי הפוזיציות הפתוחות. אם אין הרשאה לאוסף החדש, המערכת ממשיכה לעבוד ומציגה את מגמת הרווח הממומש מהעסקאות הסגורות בלבד.

אם כללי Firestore מוגבלים לאוספים מסוימים, יש לאפשר למשתמש המחובר קריאה וכתיבה גם ל-`portfolioSnapshots` תחת המסלול האישי שלו.
